# maimai Q 0.13.5 管理后台删除玩家资料

本版本为管理后台补齐玩家资料删除能力，同时更新现场终端删除命令协议。现场终端与本地版为 `0.13.5`（构建号 `71`），管理 App 为独立版本 `0.13.2`（构建号 `68`），队列网站继续使用已发布的 `0.13.4`。

## 变更

- 管理后台玩家资料页新增“删除资料”入口，使用明确的不可恢复确认对话框。
- 删除请求包含资料修订号和更新时间，服务端在终端在线且仍由管理后台接管时创建幂等命令。
- 现场终端拒绝仍有排队登记、资料版本已变化或管理后台已解除接管的删除请求。
- 现场终端确认删除后，服务端清理玩家资料、网页账户、登录/绑定/创建会话、当前资料索引、队列私密联系人、历史事件收件人和玩家编号别名。
- 删除墓碑阻止旧终端快照重新创建已删除资料。
- 营业时间、机台分组和完整机台管理（增删机台、备注、类型、服务器、版本、容量、计划时间、停用/恢复）纳入管理后台接管范围；接管后现场终端相关编辑控件置灰并提示只能从管理后台修改。
- 普通队列操作、全队列拖动排序、登记位置调整以及管理后台命令在现场终端的实际执行不受影响；自动闭店仍由终端按营业时间规则执行。
- 普通队列拖动和其他日常队列操作不受管理后台绑定限制；删除属于明确的风险操作。

- Android：local、terminal、management 单元测试和 `queue-core` 测试通过。
