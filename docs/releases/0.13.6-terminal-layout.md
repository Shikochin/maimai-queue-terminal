# maimai Q 0.13.6 终端宽屏布局与中点间距

## 本版范围

现场终端和本地版为 `0.13.6`、构建号 `72`。管理 App 仍为独立版本 `0.13.2`、构建号 `68`；网站继续使用已发布的 `0.13.4`，QQ Bot 继续使用 `0.3.13`。

本版处理此前中断的两个终端细节：

- 为 `2000×1200` 横屏显示适配首页和终端内部页面。首页主体使用标题下的剩余高度，多机台按可用高度动态分配，页面宽度在宽屏上使用实际可用空间；普通平板仍保留紧凑宽度限制。
- 统一 Android 中点 `·` 的显示。普通文本会移除中点两侧的普通空格、制表符和 Unicode 空格；Header 等结构化 UI 的独立中点使用固定视觉单元，避免字体自身 side bearing 再叠加文本空格。

同步总开关、同步模式、服务器地址和终端令牌的远程迁移/故障恢复，网页账户绑定或重新绑定，以及多终端联动仍不属于本补丁；这些功能需要完整的服务端协议、权限、离线恢复和跨端测试，继续按 [`docs/roadmap.md`](../roadmap.md) 规划。正常全队列拖动仍是日常队列操作，不属于敏感设置。
